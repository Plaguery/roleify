# About

This is a Discord bot which gives users roles based on whether or not they own a Roblox badge.

# Development

# Commands

Role
This is the main command. It takes the following inputs:
Role: This is the role to give the user if they own the badge
badgeid: This is the id of the Roblox badge to check for
API Key: This is the BloxLink API key for the server a command was ran in. It is required since BloxLink API keys are server specific. The default API key will NOT work unless you are in the server this bot was developed in.
